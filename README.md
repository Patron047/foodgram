# Foodgram — Сайт с рецептами 🍳

Foodgram — это веб-приложение для публикации рецептов, подписки на авторов, добавления блюд в избранное и формирования списка покупок. Проект представляет собой SPA (Single Page Application) на React с REST API бэкендом на Django REST Framework.

## 🔗 Ссылка на проект

Проект развернут по адресу: https://foodgrm.sytes.net

## 🛠 Технологии

### Бэкенд
- Python 3.12
- Django 4.2+
- Django REST Framework
- Djoser (аутентификация и регистрация)
- django-filter (фильтрация рецептов)
- PostgreSQL (продакшен) / SQLite (разработка)

### Инфраструктура и деплой
- Docker & Docker Compose
- Nginx (reverse proxy, раздача статики)
- Gunicorn (WSGI-сервер)
- GitHub Actions (CI/CD)
- Docker Hub (хранение образов)

### Фронтенд
- React
- React Router DOM

## ⚙️ Установка и запуск локально

### Требования
- Python 3.10+
- Docker и Docker Compose

### 📋 Возможности API
Полная спецификация доступна по адресу: /api/docs/ после запуска проекта.
Основные эндпоинты:
Аутентификация: регистрация, получение токена, смена пароля
Рецепты: CRUD, фильтрация по тегам/автору/избранному/корзине, пагинация
Подписки: подписка/отписка на авторов, список подписок с рецептами
Избранное: добавление/удаление рецептов
Список покупок: добавление/удаление, скачивание TXT-файла с суммарными ингредиентами
Профиль: просмотр, смена аватара (base64)
